# sql

SQL that is not a migration. Schema changes live only in `database/migrations/`.

| Folder | Contents |
|---|---|
| `verification/` | Read-only checks that compare the live catalogue with the approved design. Run after migrations; each result has `status` and `failed_checks` columns. |

Scripts 01 to 10 check structure; scripts 11 to 14 check data. Scripts 11 and 12 give the same result before and after the pilot transactions and the replenishment pilot; script 13 stays valid after the replenishment pilot (receipts and transfers after the pilot's last event), not after returns, adjustments or more orders; script 14 is meant for right after the replenishment pilot. Scripts for earlier migrations keep working after later ones: objects they do not know appear as INFO. One exception: after V007, script 07 shows 2 WARN rows for the two V007 triggers on the V006 tables `orders` and `payment_attempts`. They are expected; script 10 checks them. When a later migration adds tables, its verification scripts are added here with the next numbers. Later folders: `analytics/` for warehouse and reporting queries.
